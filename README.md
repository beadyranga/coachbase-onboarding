# CoachBase Onboarding

This repository is how people sign the CoachBase NDA before they get access to
the private CoachBase code. It contains no CoachBase code.

## To get access

1. Read the [CoachBase NDA and Contributor Agreement](NDA.md).
2. Go to **Issues → New issue → Sign the CoachBase NDA**.
3. Fill in the form and submit it.
4. You'll get an invite to the private repository once your signature is
   confirmed.

Your signature issue is public: your name, GitHub username and the date are
visible to anyone. Don't put anything else personal in it.
